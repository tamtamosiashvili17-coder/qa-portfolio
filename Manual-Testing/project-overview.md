# Onboarding System Testing

## Project Overview
Tested the onboarding module of a web-based HR system. The goal was to identify issues affecting user experience, system behavior, and business logic.

## Scope of Testing
- UI Testing  
- Functional Testing  
- Validation Testing  
- Localization Testing  

## Features Tested
- Onboarding task management  
- Applicant status changes  
- Sorting and filtering functionality  
- Task creation and deletion  

## Tools Used
- Jira  
- Chrome Browser  
- Figma  

## Key Results
- Identified and reported multiple bugs across UI, logic, and validation  
- Found issues related to sorting, incorrect system behavior, and missing confirmations  
- Improved overall system reliability through detailed testing
