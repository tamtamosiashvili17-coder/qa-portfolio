# Hiring Manager Module Testing

## Project Overview
Tested the Hiring Manager module of a web-based HR system with focus on permissions, validation, business logic, and UI behavior.

## Scope of Testing
- Permission testing
- Access control testing
- Validation testing
- UI testing
- Functional testing

## Tools Used
- Jira
- Chrome DevTools
- Figma

## Key Results
- Identified multiple issues related to access restrictions, validation logic, and incorrect system behavior
- Reported bugs affecting usability and business rules
